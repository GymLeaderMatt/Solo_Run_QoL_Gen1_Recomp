# In-Game Options:
- Running Shoes: on/off toggle.
- Run Button: Hold B, Toggle, Always on.
- Auto Scroll: on/off
- Hold Delay: set the number for how long it delays until it does it.
- Repeat Speed: how fast it auto scrolls holding down the button.
- Repel Prompt: on/off toggle

# Running Shoes:
- Running shoes are with you from the start. Default is holding 'B' to get a 2x increase in speed.
- You can change this to be always on or a toggle if you prefer.
- These work indoors.
- Since the default is 2x speed, I've also upped swimming speed as a baseline and have the bike be slightly faster than the shoes.
- Originally, the bike was 2x faster than the shoes and I couldn't control it so it has a 1.25 divider now.
- Technical terms: Walking: 16 frames, Running: 8 frames, Bike: 6 frames, Swimming 8 frames.
- This speeds up a pretty slow game fairly significantly. Turn it off if you don't want it.

# Auto Scroll:
- In vanilla, you have to tap the up or down button repeatedly to find what you want.
- This makes it to where you can hold down the button and it basically uses a turbo function to make those clicks for you.
- This is a massive quality of life buff that can save you hundreds of clicks even in a short playthrough.
- The options for this one is how long you have to hold for it to kick in and how many times the button press repeats.

# Repel Prompt:
- Huge quality of life change. When you run out of a repel, a dialogue box simply asks if you want to use another on in your bag.
- This defaults to your lowest quality repels. You can change the code if you want to.
- For example, if you have a max repel on, run out, AND you have a regular basic repel in your bag, it will be used.
- So get rid of your lower quality repels if that bothers you.
